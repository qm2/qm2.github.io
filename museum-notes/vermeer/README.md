# 维米尔

运行 `python3 scripts/build_vermeer.py` 更新专题和欧洲绘画入口；运行 `python3 scripts/build_museum.py` 更新博物馆首页。

- 20件作品：15件用户照片，5件补充图。29张上传图片中的14张展签不公开。
- 用户确认2025年8月在弗里克看过全部五件。三件书信展作品与另两件馆藏分开描述；借展作品按所属收藏机构筛选，五件观看记录另有共同筛选项。
- `data/works.json` 保存馆方资料链接、题材、比较关系和图片署名。
- `data/photo-manifest.json` 保存原始文件与作品/展签配对及SHA-256，用户照片逐字节保留。
- `data/image-sources.json` 保存五张补充图的来源、下载地址、公共领域说明及SHA-256。它们是Commons标记为公共领域的忠实复制图，并非弗里克专门授予本网站的使用许可。三张来自馆方或Google艺术项目，一张来自爱尔兰国家美术馆，一张来自Web Gallery of Art；具体以各条来源为准。
- 不把未在照片中出现的其他馆藏推断为用户看过，也不把都柏林的借展作品当成用户到过都柏林的记录。
- 页面“看画”为可核对的画面提示，不是代写个人回忆。

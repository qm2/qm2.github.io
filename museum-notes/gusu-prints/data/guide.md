# 怎样进入姑苏版画：给以后观看留一副框架

## 一、先认清三个词

**姑苏／苏州版画**在本辑指以苏州生产、流通为中心的一批早期商业单张木版图像，重点是清代康熙至乾隆时期。它包括城市、园林、仕女、花鸟、博古与戏曲等题材，也包括不同大小、印色与后加工方式。不是一个题材或一种固定面貌。

**桃花坞年画**与苏州商业木版有密切历史联系，但不能把两者在所有时期、用途和风格上画等号。本次许多精细单张是墙上陈设、礼赠或名胜图像；不能因为它是木版、有吉祥题材，就全部称为春节专用年画。[L2945、L3013、S02]

**丁氏作坊**是理解本次花鸟小品的重要线索。丁亮先题署及相关印本，可以把诗题、吉祥寓意、套色与纸面压印放在一起看。但同一面墙上没有签名的作品，不会自动成为丁亮先作品；作坊、绘稿、刻版、印刷与题署也不应混为一个“作者”。[L3029、L3031、L3033]

## 二、为什么会有这样的城市图像？

17世纪，南京、苏州、杭州和徽州等地的印刷活动，把书谱、图样与单张图像带给不同的使用者。到了这些苏州单张里，精细图像又能进入宅室、成为礼物，或作为名胜的纪念。[L2945]

从照片本身可以看见几种需求：有人希望房间显得清雅，有人愿望家人平安、子弟得第，有人喜欢看时髦服饰和深宅园林，也有人愿意把戏台或故事带回家。理解它们时，“艺术”和“商品”并不需要被拆开：一张能流通的印刷品，同样可以有精湛工艺和复杂观看。

## 三、时间线：三个层次要分开

| 时间 | 本辑的锚点 | 观看时的作用 |
|---|---|---|
| 约1625—1644 | b01：晚明刺绣图样 | 晚明的纸上图样，为刺绣提供人物与景物 |
| 约1633 | 南京胡正言编 b02 | 彩印模拟笔墨、颜色和不同物象 |
| 1662—1722 | 康熙时期渔家与戏曲，g12、g13 | 认识密集、叙事性强的早期单张 |
| 1662—1735 | 跨康熙至雍正的题材，g14、g21 | 较宽断代不能强缩成某一年 |
| 1700—1750／18世纪 | 丁氏相关花鸟与博古小品 | 日期多为馆方宽断代，不等于所有印本同年制作 |
| 1736—1795 | 乾隆期美人、园林、名胜 | 大幅陈设图像、成套作品与空间试验 |
| 19世纪 | 战乱、生产环境改变与新印刷方式 | 馆方将太平天国时期破坏与石印兴起列为木版衰落背景；不据此认定每张印本的损毁原因 [S06] |
| 1990年代起 | 冯德堡搜集早期苏州版画 | 近代的重新辨识和研究，不是制作年代 [S04] |
| 2025 | CMA与Met购藏冯氏旧藏中的重要一批 | 两馆各逾100件，CMA113件；不是本次展出的数量 [S02、S03] |
| 2026 | 本次观看、专题整理 | 11月13—14日提前开放所见；11月15日起正式展出 |

另有一个更早的时间：赤壁208年、宋代杨家将背景属于**图像所叙的故事时代**，并不是纸张或版画的制作时代。

## 四、四个步骤，看懂“印出来的画”

1. **看线。** 线条划出人物、花瓣、衣纹与建筑。密排线还可以承担阴影、水纹和天空的效果。g14、g29适合比较西方铜版视觉在木版中的转译。
2. **看色。** 多色可能来自不同版块先后印刷，也可能有后期手工补色。同一张画可以兼具印刷与笔绘，不应把所有颜色说成一次印出。
3. **看对位。** 不同版块需要准确对应。g07中的横向接缝，是大图分块制作的现场线索；g24的蓝黄叠绿，说明颜色数与版数也不总相等。
4. **看纸。** 拱花利用不着色的版压出起伏，使花瓣或果实表面产生浮起的质感。本辑以展签记录为依据；正面照片未必能显出全部压纹。[L3012、L3033、L3037]

### 术语小卡

| 词 | 简明理解 | 避免的误会 |
|---|---|---|
| 套色／分版 | 用不同版块逐次叠印颜色 | 不等于一块版或一次完成 |
| 饾版 douban | 将画面分成较小版块来处理，配合准确对位 | 不把所有多色印刷都严格归成同一工法 |
| 拱花 gonghua | 无色压印造成纸面起伏 | 不是白颜料，也不是纸面自然皱褶 |
| 印本 impression | 从版上印成的一张／一件 | “目前所知孤本”是仅知一张存世，不表示原来只印一张 |
| 后加色 | 印后再用笔设色 | 不必然与原版同地同年完成；g02保留可能的欧洲设色 |
| 线性透视 | 用线条汇聚等手段制造纵深 | 木版模仿铜版视觉，不会因此变成铜版媒介 |
| 博古／清供 | 古器物、花果与雅致陈设的图像世界 | 画里有古物，不代表买画者真的拥有这些古物 |

## 五、祝辞不是密码本

看花鸟时，先辨具体物象，再结合题诗和可靠说明。玉兰、海棠、牡丹可组成玉堂富贵；石榴籽与“子”连成多子祝愿；“状元红”荔枝将颜色连向科举；画眉的题句把鸟与遂意联系起来。[L2976、L3025、L3027、L3041]

但不是每只鸟都必然叫喜鹊，不是每朵花都只有一个寓意。《寒夜栖鸟》尤其值得保留一层直接的感受：先看到两只鸟挨着睡，才知道冬季植物的组合。典故帮助观看，也不应该挤走观看。

## 六、江南与远方：地点怎样放在一起

本辑地图分两层。第一层是生产和图像里的江南：**南京**对应书谱编印；**苏州**对应作坊、阊门、胥门与虎丘；**杭州**是苏州刻工所画的西湖。生产地、所画地点与今天的收藏地，各有不同的位置关系。

第二层是流传与收藏的具体例证：奥地利Eisenstadt的Esterházy宫留有同版《冬》印本；捷克Veltrusy庄园留有同版画眉印本；日本与欧洲收藏保存了许多早期苏州图像；2025年购藏后，两家美国博物馆成为重要研究地点。下方按这些关系分层列出，帮助把地点接回作品。[L3041、L3054、S02]

## 七、以后遇到一张新作，问这七件事

哪里制作？画的又是哪里？年代是宽断代还是有纪年？单张、成对还是套画？印刷和手绘各做了什么？题诗、铺号与作者签名说了什么？今天见到的是哪张存世印本，而不是哪种图样？

这几项比记住一串“精品”更有用。它们让下一次观看可以接着这次继续。

## 内容与证据

- `data/works.json` 是内容源：保留交接编号、英文题名、展签原始地区/年代/材料、中文显示字段、归属、主图/细节/馆签、相关作品、来源、资料疑点。札记逐段区分视觉观察与馆方解释；原题名及未知馆藏号、尺寸不猜填。
- `data/photos.json` 是115张素材的对应表，记录原文件名、作品编号、角色、像素尺寸、原件SHA-256和衍生图。114张原照片及1张补充展签均保留字节一致的原件；网页使用480/960像素宽WebP，响应式候选包含原尺寸JPEG，灯箱打开原件。无裁切、生成式补全或颜色改写。
- 全部30件馆签独立打开核读，主图逐件对照，另直接检查高风险背面、修复和铭文照片。989/990与991/992、1046/1049、1056–1060/SUPP01对应确认。1037可辨“比丘法興”，与馆签Faxing相合，其余铭文不拼补。
- 1019/1020及1021/1022为MFAH自有馆藏，分别为2004.2248、91.333，不计入28件。
- 唐代干漆佛首与原夹纻干漆专题`object-259`为同一件，已记录共享身份及交叉链接。
- 来源为现场馆签、MFAH官网及馆店、耶鲁大学出版社、大都会和圣路易斯艺术博物馆的已读页面。大都会大理观音只作类型比较，不移植其来源与数据。
- 图录仅核到出版信息和介绍，未获得原书正文。旧陪读对话是检索线索，不是书页证据；未复制私人对话全文进仓库，也未引用旧助手给出的具体尺寸、成分百分数、原寺院、收藏链或组像复原。

3. X01 智慧佛：保留“可能为阿閦佛”，现代补手见馆签；原寺院、原配组像、准确修复时间和损毁经历没有确证。技术数值未核原书，不写。
4. X06/X07：分别依现场展签15世纪、8世纪。旧助手曾写13世纪与8—9世纪，只是旧答与展签不同；尚不能称图录和展签冲突。需要原书图像及条目核对。
5. X24/X26/X27 题记：只使用馆方释义及照片清楚可辨的施主名，完整释文仍缺可靠校录。
6. X25 木座：2026-10-26复核三面原照片，题记己未年对应1919年，松窗与礼堂可联系褚德彝。新增2002年佳士得本件原记录及1992、2011公开节点，详见作品数据history字段。木座印记清晰照、陕西寺院来源、端方身后至题写时的递藏关系、1992原图录及2011原始拍品页仍缺；与像身结合时间也未明。
7. X28 佛首：泥芯、漆布与去芯工艺依补充馆签；原像尺寸、具体寺院与实际参加行像的经历未核。没有用时代习俗补写个体经历。

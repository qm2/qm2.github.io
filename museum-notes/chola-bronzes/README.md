# 朱罗青铜造像

2026-11-23：作者授权制作首版并直接提交、部署。源包在 `/home/qingxi/museum/印度朱罗青铜.zip`，只读解压于 `museum/chola-bronzes-pack/`；不把ZIP、原图或研究图录放入Git。

## 数据与页面

- `data/catalogue.json`：38个稳定的观看对象ID（c01—c38），40件单体，81张原片；C14与C20各为两件组合。其余展厅中背景作品不另计。
- `data/media.json`：81张原片及2张包内裁切的文件名、SHA256、照片角色、尺寸、公开URL与响应式衍生图。同一原片只保存一次，展柜合照可由多个对象引用；3386、3387归c20，不新增作品。
- `data/details.json`：6个由原片生成的局部，保留像素裁切范围，不放大、不去反光、不改色。c20另用3387现场近照，c33另用3380背面全图。
- `data/museums.json`：12家实际观看博物馆，含借展地点。坐标仅供现代馆址导航，复用本站已采用的机构定位，新加达拉斯与奥伯林。
- `data/readings.json`：逐件文章。`stories.json`为9组神与圣徒，`history.json`为7段历史导览，`chapters.json`为首页6章，`comparisons.json`为8组并看，`sources.json`记录实际阅读范围。
- `atlas-index.json`及47个HTML页面由构建生成。年代栏按年代范围中点归类，c24/c35延续单列。顶部吸附按钮与时期选择器避免寻找底部滚动条。

## 已核实的重要修正

- 罗摩3314的馆号是 **W1982-106-1**，约975年；费城收藏，作者确认在MFAH **Living with the Gods** 借展观看。不是费城现场。
- 3318为Met **62.265**，10世纪第三季度；不采用初审疑似编号。
- 三叉戟3346为CMA **1969.117**；舞王3354为 **1930.331**，馆方写1000s即11世纪，不改成约1000年。
- CMA **1961.94**的现行馆录约1020—1040年，现场旧展签约950—960年；正文用现行断代，资料注保留差异。照片显示两尊**站立**，不能与纳尔逊的坐姿组合混写。
- 3370的舞王 **F2003.2** 已归还印度政府，继续借展NMAA；2026年馆方公告与现场来源牌3372支持。收藏与观看分栏。
- 华盛顿圣童 **F1976.5**、南迪 **F1985.30**；金贝尔毗湿奴 **AG1970.01**（3379正面、3380背面）已核实。
- 作者确认3373/3375/3377均摄于NOMA，3379/3380摄于金贝尔，3388摄于NMAA。参观日期未给出，均留空，不由文件名推算。
- c31为Bhansali私人借展耆那像，非印度教；c34为Hendry私人借展，非SAMA自有。
- 约1300年的c24及13—14世纪c35列作晚期延续，不把所有作品都称为有王室委托记录的朱罗宫廷制作。

## 名称与研究范围

朱罗、湿婆、毗湿奴、罗摩、哈奴曼、乌玛、帕尔瓦蒂等沿用通行中文。Sambandar采用大都会中文官网“森班达尔”。Karaikkal Ammaiyar、Chandikeshvara、Manikkavachakar等未找到足够可靠的通行中文人名时，使用自然的中文身份题名与英文并列，保留可搜索原名。

主要研究为现场展签及CMA、Met、NMAA、Kimbell、Walters、SAM、PMA、Allen馆方记录；UNESCO神庙页面、NMAA神庙／巡游导览提供历史背景。直接阅读Dehejia《The Very Idea of a Portrait》（Ars Orientalis 28，1998）41—44页关于王后与圣徒的讨论；不转载论文图片，不冒称阅读其全部引文。

尚待继续研究：c31的具体耆那身份与编号；乌玛的王后肖像说；多数作品的原神庙、工坊和完整递藏链。Nelson女圣徒已核对公开记录中的基本资料与早期展览题名；故事依据现场展签，不把网上列出的旧著录当作已读全文。

舞王：让变化有一个身体

湿婆 · Shiva / Nataraja

鼓与火讲变化，伸出的手和抬起的脚讲保护。

湿婆不只是“毁灭之神”。舞王把创造、消解和庇护放在同一个动作中：小鼓带来节奏，火焰使世界消解，一只手安抚观者，另一只手引向抬起的脚。脚下的无知被压住，舞蹈因此既强烈，也提供可以依靠的地方。[资料]

先看身体的支点，再看鼓、火与两只前手；没有持物时，保留缺失本身，不凭相邻作品硬补。

乌玛与帕尔瓦蒂：女神的多种面容

Uma / Parvati

名字可以相通，站立、安坐和组合各有自己的观看方式。

乌玛、帕尔瓦蒂都是与湿婆相连的女神名称。她可以在神的家庭中出现，也可以成为独立礼拜的对象。本辑从站姿女神到成对坐像、立像，展现的不是一张固定面孔，而是身体与关系的不同安排。[资料][展签]

象头神：一次冲突，成为新的开始

Ganesha · 伽内什

守门的孩子 → 与湿婆冲突 → 换上象头复生。

现场展签采用的传说中，帕尔瓦蒂创造了一个孩子为自己守门。湿婆归来，不知孩子身份，与他发生冲突；发现真相后，以象头使他复生。这位神因而既是家庭中的孩子，也是人们开始旅途、婚姻与事业时寻求帮助的对象。[展签]

从象鼻、断牙、甜食与圆腹进入，比只凭“象头”更容易看见具体作品的趣味。

罗摩与哈奴曼：一场寻找与营救

Rama · Sita · Hanuman

悉多被劫 → 哈奴曼寻找 → 罗摩展开营救。

罗摩是毗湿奴的化身，也是《罗摩衍那》的主人公。妻子悉多被魔王罗波那掳走，哈奴曼加入寻找和营救。在史诗中，他有越海与搬山的能力；在礼拜形象中，却可以低首举手，把力量转化为忠诚。眼前的罗摩持弓姿势与哈奴曼的谦恭，分别留下同一故事的两种性格。[资料][资料]

罗摩原持的弓已缺失；哈奴曼的猴脸、尾巴和靠近嘴边的手，比“威武”更有辨识力。

人狮：胜利之后，也能静坐

Narasimha · 那罗辛哈

魔王自恃不死 → 人狮在黄昏现身 → 信徒得到保护。

大英博物馆介绍的版本中，魔王得到特殊保护：人或兽、白天或黑夜、室内或室外，都不能使他丧命。他威胁信奉毗湿奴的儿子时，神以半人半狮的形体，在黄昏的门廊出现，打破这些条件。神话解释人狮的力量；本站两尊铜像却选择瑜伽静坐，让这股力量转为专注。[资料][资料]

狮面辨认化身，膝部与束带辨认冥想状态。不要把静坐像描述成眼前正在杀敌。

森班达尔：一根指向神的手指

Sambandar / Tirujñāna Saṁbandha

女神哺乳 → 父亲询问 → 圣童指向神，唱出赞歌。

森班达尔是7世纪的泰米尔诗人圣徒。在传说中，他幼年得到女神的乳汁，随即以赞歌回应神恩。后来造像将他留在孩童的形态里，一手指向上方，另一手与身体一起舞动。孩童形象并不是说这些铜像铸成于他的童年，而是用最容易记住的故事呈现他。[资料][资料][展签]

比较三件的指尖、抬腿与小腹；不要因为裸体孩童形象，就改认成幼年黑天。

苦行女圣徒：愿在舞蹈的脚下歌唱

Karaikkal Ammaiyar

供养神 → 离开世俗生活 → 以苦行的身体为湿婆伴奏。

圣传里的她曾有家庭，也有被赞美的容貌。在与湿婆有关的神迹之后，她选择远离世俗身份，请求一种能够专心礼拜的身体。铜像凸显骨骼和衰瘦，却让手中铙钹保持活力。她的故事使“美”不再只有年轻和丰腴，也包括对一件事毫不保留的投入。[展签]

看支起的膝、胸前的小钹与微张的嘴；瘦削来自圣徒传记，不据此把她叫作迦梨。

迦梨：可怖为何也能保护

Kali

恶魔的血不断生敌 → 女神阻断再生 → 危险被制止。

克利夫兰馆方讲述女神与恶魔的战斗：血一落地就会产生更多对手，迦梨因此将血饮尽。她的激烈形象对应危险的规模，而不只是无缘由的暴怒。神话里的力量在铜像中被整理成站姿、持物与头部装饰，让礼拜者能够面对。[资料]

先看这件像实际保留的手和姿态；不把其他迦梨图像的舌头、脚下人物等搬到这里。

耆那：不动的身体，也是一条道路

Jina · 耆那教觉悟者

战胜的不是敌人，而是使人受缚的欲望。

耆那教尊崇超越轮回的觉悟者，并强调不伤害生命。站立弃身冥想让手臂自然垂下、与身体略分开，以不动体现高度克制。裸形与缺少装饰，在这里表达放下占有，和朱罗神像的华服、首饰并存于同一时代。[资料]

看身体的正面性和双臂间的空隙；仅凭现在的照片与展签，还不能指定他是哪一位耆那。

# 永宣宫廷造像

独立小专题 `/museum-notes/yongle-xuande/`，四件核心、一件对照与三件仪式器物。七条权威记录对应八件实物：仪式斧和钺刀沿用既有同框组合记录，不按照片张数计作品。没有新增年代相近但宫廷归属未证的藏品。

## 数据与构建

- `data/topic.json` 只存专题札记、阅读顺序、照片引用与资料注；身份、尺寸、收藏、材料和照片分别复用 `../himalayan-art/data/works.json`、`photos.json`、`derivatives.json` 及 `sources.json`。不建立第二套藏品事实。
- `scripts/build_yongle_xuande.py` 生成完整阅读页与作品链接兼容页。全站 `python3 scripts/build_museum.py` 在喜马拉雅生成之后调用它。单独开发先运行 `python3 scripts/build_himalayan.py`，再运行本生成器。
- 核心为w1643（西雅图59.59）、w1512（大英1908,0420.4）、w1516（柏林I D 31831）、w1567（克利夫兰1972.96）。对照为w1486（赛努奇M.C.686）；器物沿用w1571（1978.9.1、1978.9.3）与w1572（1983.154）。
- 封面h1657；观音正文h1643、赐款近照h1658；其他四幅完整主照片为h1512、h1516、h1567、h1514。h1486在赛努奇“另一次观看”中展开。孔雀组合与全图均按自然比例；未裁去坐骑、尾羽、手足或莲座。
- 全部作品图片复用个人摄影，不复制外部图像、技术论文插图或图录书页。新导入仅h1486与h1514两张原片及各三档WebP，不重复复制既有文件。原图SHA-256、包内角色与处理决定见 `data/intake.json`。
- 独立展签按既有 `do_not_publish` 约束留在本地原包，网页使用已核对的基本资料与必要文字差异；没有为这轮将全部标签批量公开。毗瓦巴h1568横置的展签也未被当作作品图展示。

## 合并、观看与链接

赛努奇w1486与w1514确认为同一M.C.686，纠正旧交接包的“不同件”。`work_aliases.json` 将w1514映射到w1486。两个作品页旧路径及首页的旧work查询/片段可继续到达同一件；新专题也接受两个ID。两组原片各自有参观记录ID和配对展签。用户确认红底h1486为2024年12月赛努奇本馆，白底h1514为2025年8月纽约Met借展，并与大英w1512同次观看；`visited_month`记录月份，`visited_on`不补造具体日。

权威数据新增一条公开对照，喜马拉雅默认目录保持112条。`himalayan_default_inclusion:false` 排除它的默认目录、筛选与地图；独立作品资料页仍存在，主面包屑回中国佛教艺术与永宣专题。作品记录总数113与默认112区分统计。新专题入口不会把它自动改为藏式作品。

大英与柏林两件的收藏机构不变，`display_museum_id` 改为用户确认的 `met`；它们出现在纽约观看地图而非伦敦、柏林。制作地区继续独立记录。柏林馆录“北京？”没有变成确定制作地址。

喜马拉雅 `topic_links.json` 生成“专题深读”两卡；首页首屏锚点、第六章与u23分别通往新专题，摘要保留。丹萨替原锚点不变，新增返回喜马拉雅、帕木竹巴、13—16世纪寺院网络与形象导览。中国佛教艺术新增第七张造像专题卡；博物馆首页仅在已有板块下加短链接。专题数由实际入口计算。

## 资料核对与限度

- 已打开西雅图馆录、Met大英借展记录、柏林对象记录及所转载Bröskamp作品说明、Cleveland各件馆录/打印页、巴黎市立博物馆M.C.686记录；逐张核对包内作品原片与展签。来源就近短注，完整标题集中页末。
- 已读Quanyu Wang、Sascha Priewe（2013）技术论文61—68页：佛身及一体莲座高37厘米；黄铜失蜡铸造与铜板方台/背光有别；后两者更可能18世纪增配。保留判断程度，不把合金测定当绝对断代。论文转引的旧全球数量不采用。
- 大英现行对象页403、赛努奇自身页503维护，不声称核读其正文；采用Met、论文、巴黎馆录及实拍展签。柏林2023整本图录未读；Cleveland列出的Karmay、von Schroeder、Circle of Bliss等书仅是书目线索，未当作已独立查阅依据。
- Seattle两张签为1425—1435，官网15世纪；年号表述用1426—1435并留差异注。“三件宣德款”限某次西藏寺院调查，未推广成全球数字。
- 柏林145厘米含尾羽、94厘米不含尾羽，均非主尊独高；主尊独高未查得。具体工坊、受赠者、尾羽与接合年代仍不确定。
- Virupa作为密教大成就者；指日属于宗教传记。来源仅写馆方所录加德满都商人、1965—1972纽约Klejman、1972入藏。CMA自动图片alt左右手不采，按原片写“举臂指日、另一手持器”。
- 斧的1407赠献为馆方推测；刀的赠献为其单件馆录解释；香炉联系1407见现场共用展签的推测，现行对象页未确认独立赐款。并柜不认原套。

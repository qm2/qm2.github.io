造像与发愿

南北朝的佛教信仰
约五至六世纪

石会风化，人的姓名却有时
因一尊佛像而留存。

十五件亲见石刻，从佛的面容，读到为父母、师长与众人留下的愿望。

从一份发愿看起 ↓

南北朝的造像碑上，除了佛与菩萨，还有许多我们原本不会认识的人。有人为亡父造像，有人与母亲共同发愿，也有人与数十、数百位信众一起，把名字留在石上。

这一辑从我在不同博物馆亲眼见过、亲手拍下的作品出发。先看形体，再绕到背后，读一读他们为何造佛、为谁造佛，又怎样在石头上想象未来。

01 / FAMILY / MEMORY

为父母造佛

在成都，释法海与母亲为亡父造弥勒；在北魏，尹受国盼望父亲生生得遇佛法。不同的主尊、不同的家庭，把对逝者的牵挂放进了比一生更长的时间。 [1] [2] [3]

南齐 · 490年

母子同心，等待弥勒

正面衣摆落向台座，背面文字则记下母子二人的发愿。490年的这件小像，从“亡父”出发，又把在世眷属、七世父母与一切众生都列入祈愿。 [1]

石像承载的不是父亲的容貌，而是希望他在未来闻法的心意。

02 / DONORS / COMMUNITY

从一人到众人

一位僧人的愿望可以通向一切众生；多人营造的碑，也会保留不同身份与分工。功德回向与共同出资，是两条彼此相接、却不完全相同的线索。 [4] [5]

北魏 · 526年

“等成正觉，所愿如是”

法兴在526年的台座上写下国主、师徒、父母、眷属。最后又加上“一切众生”。读到这一步，造像就不只是为某个人留福，而成为共同趋向觉悟的愿望。 [4]

这尊在休斯顿所见的三尊像，也收在虚舟收藏一辑。这里沿着台座上的发愿文，重新走近它。

北魏 · 528年

七十人的名字

七十人的共同参与，出现在题记中，也出现在正背与两侧的供养人行列里。走近看人物的大小和位置，会发现“集体”并不抹去其中的身份差别。 [5]

由这件碑往后看，五百余人的修寺工程与道林身旁约二百位供养者，又把共同营造的规模和方式继续展开。 [6] [7]

03 / FRONT / BACK / BEYOND

石上的佛国

一块碑不止有一个正面。燃灯佛、弥勒、释迦与多宝，以及经中人物的问答，可以占据不同的层面。视线绕行时，石上空间也在不断改变。 [8] [9] [10]

西魏 · 约537年

从大龛走向细小的场景

主龛中的佛是入口，周围小塔、火焰纹和一排排人物让目光停留。馆方将不同场景联系到《法华经》及佛传；这块约537年的碑，需要远看轮廓，也需要走近逐层分辨。 [9]

正背、上下与局部的十张现场照片收在作品页。先找各层的边界，再辨人物关系，比急着一次读完更从容。

04 / TWO PLACES / MANY FORMS

成都与北方

成都四件造像的出土地点与纪年，为比较提供了清楚的起点：511年的一件来自商业街，其余三件来自西安路。它们与北方石刻相近的背屏形制，并不意味着所有造型都出自同一条道路。 [1] [11] [12] [13]

可以从衣纹、人物之间的间距和背屏的使用看起。下方两件相差约三十年，体量也不同；并置是为了看清雕刻怎样安排一尊主像与周围的人物。 [13] [14]

05 / EXCAVATION / COLLECTION

石佛远行

今天的博物馆陈列，是这些作品生命中的后一段。考古出土、旧收藏、交易与入藏各有证据，不能把不同作品写成同一条流转路线。

  1. 1995年出土

    张元造释迦多宝像

    成都西安路出土。明确的发现地点，让这件545年造像成为理解当地南朝艺术的坐标。 [13]

  2. 1959年入藏

    尹受国造释迦佛像

    馆方记曾经京都K. Moriya与东京壶中居收藏，1959年购入纳尔逊。更早的原寺院与离华经过仍有空白。 [2]

  3. 1932年入藏

    道林与众人造像碑

    馆方来源记录起于山西长子县，经北京收藏与交易网络，1932年进入纳尔逊。具体原供奉建筑未明。 [7]

  4. 2017年拍卖

    法兴造释迦三尊像

    1940年前已入藤田收藏，后为藤田美术馆旧藏；2017年见于纽约佳士得拍卖，如今在休斯顿以虚舟收藏展出。拍后怎样流转，不由这些节点自动补全。 [4]

“为亡考”“师徒父母”“一切众生”，这些文字把造像与具体的人重新联系起来。照片留下眼前的形体，录文则让我们听见其中一部分愿望。还有些姓名与经历尚不清楚，留给以后的观看与阅读。

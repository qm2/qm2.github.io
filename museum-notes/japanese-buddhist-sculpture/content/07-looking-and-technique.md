# 怎样看木雕：从一处细节回到整个身体

### 先用三个距离
远看轮廓和尺度；中距离看头、肩、躯干、双腿怎样相接；近看木纹、漆、金饰和损伤。每一次靠近之后，再退回全身。宁静和力量常常来自各部分的关系，不只来自一张脸的表情。

### 木胎与表面，是两组问题

::photo j14 3139 露出的木胎与残存表面：从腿部木纹回看全身::

一木造（ichiboku-zukuri）以主要木块组织身体，不能被简化成所有细部绝不另接；寄木造（yosegi-zukuri）通过多块木材组合成像。掏空可以与不同构造方式结合。木材鉴定则依赖解剖特征与科学分析，不能凭普通照片的颜色定为桧木、榧木或檀木。[S-WOOD]

漆可以参与表面构建与处理；彩绘、金箔、金泥或截金又是更具体的装饰问题。材料栏只写“木”，也不说明它原先必定裸木。截金以细金箔条、片铺成纹样，近看时可以留意衣缘与宽阔衣面怎样安排不同的装饰。

### 玉眼与身体内部

::photo j23 3161 克利夫兰阿弥陀：可放大面部，将所见眼睑与馆方嵌眼记录对照::

玉眼（gyokugan）是以水晶等材料嵌成眼部的工艺。克利夫兰阿弥陀与圣安东尼奥地藏有馆方或展签的水晶嵌眼记录；在放大图中找眼睑和眼球的相接处，再将所见与材料记录对照。[S-CMA-AMIDA][L3255]

内部也可以保存文字。[康俊的阿弥陀](/museum-notes/japanese-buddhist-sculpture/j23/)留下经文、制作记录与结缘名单，金身外的纹样和像内的人名，由此相接。[S-CMA-AMIDA]

### 照片里的观看距离
全身照片保留形体的关系，面部与衣纹近照则把目光带到手工的尺度。j12与j58的组合，还让我们看见像与像之间的空隙。光背的尖端、扬起的手、足下莲座，以及展柜中的反光，共同保留着这次现场观看的条件。

### 常用词速查
| 词 | 在本站怎样使用 |
|---|---|
| 如来／Nyorai | 佛的一类称谓，仍需辨明释迦、阿弥陀、药师、大日等身份 |
| 菩萨／Bosatsu | 以求觉悟、救度众生为志向的形象；观音常具冠饰，地藏常作僧形 |
| 明王／Myōō | 密教中以威猛形象表现保护与降伏的尊格，如持剑与索的不动 |
| 来迎／Raigō | 阿弥陀及侍从迎接往生者的图像，可看举手、垂手、承莲与云座 [S-MET-KYOTO] |
| 智拳印 | 右手握住竖起的左手食指；Met将其联系到精神与物质的结合、对烦恼的制约 [S-MET-DAI] |
| 截金／Kirikane | 将极细金箔条、片铺成线条与纹样的装饰工艺 |
| 仏师／Busshi | 佛教造像制作者的称谓；一个作品可能涉及工房协作 |
| 传、周边 | 区分推定作者、工房关联与确定署名的用语 |
| 神佛习合 | 本土神祇信仰与佛教长期结合的现象，僧形八幡是可见的例子 [S-KIM-HACHI] |

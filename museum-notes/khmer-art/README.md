# 高棉艺术：水、山与神的身体

由2026年11月27日用户交付的 `museum/khmer-art-codex-pack.zip` 建立。范围为前吴哥、吴哥及相关泰国东北部传统；暂不收入占婆。58条记录不是58件古代原作，包含组合、三条近代翻模、一条模型、一条仅展签及一条身份未定记录。全部120照片均保留，11家机构是实际观看地点。

## 维护与构建

- `data/objects.json` 是本专题记录权威；沿用交接ID，馆藏号另存。未提供到访日期不填。
- `data/photo_manifest.json` 保留原始文件SHA256和分配；`media.json`是响应式资源、转正角度、图注、原片URL。原图不裁切、不去反光、不补画。
- `data/readings.json`维护六篇完整阅读正文，来源标记`[[S01]]`与现场照片`[[P3636]]`紧邻论断。
- `museums.geojson`与`origins.geojson`分别表示城市观看地点与古代原址／关联，后者保留明确原址、原型、候选、区域及风格背景。底图复用Homer的Natural Earth公共领域数据，无传播路线。
- `timeline.json`保留交接年代记录；页面年代统一由objects产生。modern_display与ancient_art分轨；约年和范围的文字优先，未知年代单列。组合可覆盖组内不同年代，不以中点作为制作年份。
- `atlas-index.json`由构建派生，地图、目录、时间线用同一组记录与筛选。URL保留q/museum/kind/category/material/view/site/region；浏览器返回恢复条件。未加载JS仍有全目录、年代和地点链接。
- 新照片沿用作品ID追加，新的作品另建记录；重复记录不得靠近似外观合并。来源的交接查阅范围与实现复核范围分开保存。

```bash
python3 scripts/build_museum.py
python3 scripts/check_khmer_art.py
python3 scripts/check_khmer_browser.py http://127.0.0.1:8774
```

## 图片与发布

原包保持在仓库外。`prepare_khmer_images.py`从120原片生成400、900及不超过1600像素的WebP，不放大；十张展签只旋转衍生图。原片与预览放在既有R2的 `museum-notes/khmer-art/` 前缀，全部公开GET核对SHA256和类型。仓库只存源码、数据、页面。上传清单与校验报告位于 `museum/khmer-art-assets/`，没有公开zip、研究书页、密钥或第三方图片。

## 细节与阅读精修（2026-11-28）

- `details.json` 保存8组原片裁切的像素框、原片SHA256、展示宽度、标记与图注；`prepare_khmer_details.py`可重建12个WebP衍生文件，不放大、不改色。派生局部不计入120张摄影原片。
- 编号与引线为HTML/SVG覆盖层，灯箱中的局部不带覆盖标记，另可打开完整原片。洞窟图是拍摄展签中的馆方数字复原图，保留制作团队署名。
- `periods.json`维护显式时代框架，`context_timeline.json`分别列古代与现代发现／修复史，并保留年代范围。
- `geography.geojson`来自Natural Earth 1:50m国家与湖泊数据，筛选四国及洞里萨湖，裁到区域范围并简化0.008度；源URL、许可保存在数据内。核心吴哥视图优先展开西梅奔、吴哥窟、巴戎、圣剑寺；完整关联地点仍在下方列表。
- 新增吉美2025官方展览说明和MA 5063馆录；G02的7世纪立像与19世纪大门翻模分别描述，不将现代陈列当原始组合。58条记录数不变。
- 文章地图入口携带原址与区域参数；图录默认仅搜索、观看馆及折叠更多筛选；五组细读导航提前到封面之后。

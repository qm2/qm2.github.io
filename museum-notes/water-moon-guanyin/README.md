# 水月观音：木雕主线与延展看

- 首页八件依次为 `215, 213, 226, 195, 235, 247, 251, 255`；以宋辽金为重心，**不覆盖各馆断代**。波特兰 38.52 仍是13—14世纪。
- `extended/` 收 `243, 241, 199, 224`，依用户观看安排分辑，不把四件都断成晚期。宾大仍为金或元，吉美石雕仍为宋或金。
- 作品事实、照片、旧ID仍只维护在 `../buddhist-sculpture/data/objects.json`。没有创建第二套作品记录，也没有修改原片。
- `data/guide.json` 仅维护编选、观看城市定位、延展导语、古董商关系和来源。主线/延展不重复计数。
- 将来补白瓷、铁观音：先在共享作品库登记真实作品/照片/资料，追加 `extended_ids` 和一句 `extension_notes` 即可。本轮不创建空白作品或假想材料条目。
- 地图从主线对象派生馆名与作品数量；坐标是**观看博物馆所在城市**，不是考古点。新馆须在 `map.museums` 添加城市坐标及区域；已有馆新增作品不必改HTML。Natural Earth公共领域底图复用Homer `ne_110m_land.geojson`，构建时投影，页面无需加载地图服务或外部脚本。三个分图比例不同。
- 经手分类是带角色、日期、证据的关系记录，不推导同寺院/同作坊/完整出境路线。山中两件是普林斯顿和克利夫兰；卢芹斋三件包括纳尔逊主线、宾大及沃尔特斯延展。
- 旧 `#object-*` 保留。延展四件的旧主页面锚点有缩略入口，无JS可继续点击；有JS自动进入新页面对应展开的札记。跨专题旧链接不失效。

# 纸上姑苏，烟火江南：本地第一版

2026-11-19。第一版本地实现后，用户明确授权提交与部署。本次发布仅包含姑苏专题、构建接入及两个导航入口；既有十王专题的未提交修改继续保留。

## 范围与入口

- `/museum-notes/gusu-prints/`：个人观看札记、完整母子图封面、五处局部、地点关系、六章入口、四组并看、折叠目录及展厅摄影。
- `guide/`：概念、制作工艺、时间线、祝辞及以后观看的问题。
- `collection/`：保存、冯德堡搜集与2025年两馆购藏；同版实例与本张来源分开。
- `catalogue/`：32条可搜索记录，主题、年代、重点细读筛选，URL保存条件与浏览器返回。
- `g01/`—`g30/`、`b01/`、`b02/`：32条独立作品／成组页。其中18条整合了研究包的重点长文；并非32张纸或整个展览目录。
- `sources/`：19项资料、所有现场展签与展板，S/L引用对应稳定锚点。
- 共37页。博物馆首页和中国书画增加各一处入口。

地点模块是有角色说明的非比例关系示意，不是精确地理地图，不绘制出海路线。时间线位于导读第三节，首页有直接入口。

## 维护

正文与记录在`museum-notes/gusu-prints/data/`；页面由`scripts/build_gusu.py`生成。图片准备只需首次或补拍时执行：

```sh
cd /home/qingxi/website
python3 scripts/prepare_gusu_images.py /home/qingxi/museum/gusu-prints-codex-pack
python3 scripts/build_gusu.py
python3 scripts/check_gusu.py
```

`build_museum.py`已接入该生成器。图库重建不依赖网络；图像准备以原包为只读输入。新增记录先补照片成员关系、核实信息和阅读段落，再加入章节或比较。不要直接修改生成HTML。

# 给 Codex 的专题任务

请在 Qingxi 的 museum-notes 仓库创建古罗马浮雕石棺专题。先阅读本目录全部 Markdown、objects.json 和三张联系表，再查找仓库 AGENTS.md 与既有专题模式。建议路径 roman-sarcophagi，最终以仓库规范为准。

## 用户明确表达的兴趣

“印象最深的还是在罗马国家博物馆看到的那个真的太震撼了密密麻麻高低起伏的战争场景，休斯顿的也很喜欢因为看了太多次。”

据此把波尔托纳乔作为视觉与叙事开场。休斯顿组体现长期反复观看的熟悉感。不要凭空添加参观时间、停留时长或其他第一人称经历。休斯顿的感受适用于组，不擅自声称用户只偏爱其中某一件。

## 实施范围

- 23个主要对象条目（包含新增r23，另附独立棺盖932）全部进入总目录。60张原图均纳入资源清单，其中37张为作品照片、23张为展牌。不要把不同角度当新藏品，也不要把展牌放成主图。
- 重点深读波尔托纳乔、休斯顿亚马逊、休斯顿酒神、梵蒂冈亚马逊，并以俄瑞斯忒斯、墨勒阿格洛斯和缪斯题材发展比较阅读。其余各有基本信息、短观看提示和原展牌入口。
- 全部公开图片只用用户自拍。馆方资料用于文字核验和出处链接。原图保持不变，可以生成网页派生缩略图，须保留原图放大入口。
- 首页建议为引言、波尔托纳乔主视觉、主题导览、重点深读、全部藏品、时间线与博物馆地图。地图与时间线为策划建议，用户本轮未另作逐项确认，可沿用既有专题交互。
- 时间线支持约年、区间，不能把date_start/date_end显示成精确制作起讫。地图标出现代观看/收藏地点，另有可靠古代出土地时才添加，禁止把二者混淆。无拍摄日期不生成旅行时间线。
- 波尔托纳乔1924与1925都保留，选择构图最完整的一张作主视觉，另一张进入相册。1930与1931是同一梵蒂冈陈列的远近景，内含三个独立对象，分别建r13棺身933、r23前板914与关联棺盖932，照片共用。休斯顿1953–1958可用正反面、两端和局部切换。
- 休斯顿1946–1950为同一原石棺的前板和侧板，保留2003.53.1/.2组件号。梵蒂冈932非原配棺盖，单独说明。1922上方碎片据学术学会目录对应同一石棺的棺盖，以分组件展示。
- “观看馆”“收藏机构”“古代来源”“制作地区”须分字段。r01–r04在卢浮宫拍摄的判断不等于卢浮宫拥有。
- 文案简洁、具体，先教看人物、动作、空间，再讲故事与纪念功能。神话段落只讲理解眼前图像需要的内容。
- 每篇给出可追溯来源，区分现场展牌、馆方目录与图像文献索引。null字段不填猜测。主要缺口见03，Vatican辨读见06。
- 复用站点图片查看器、导航、样式与来源展示，检查移动端横幅作品可放大看细节，检查所有图片路径和返回入口。
- 完成后报告新增路径、构建/链接检查结果、尚存身份与编号疑点。发布操作遵循用户当时授权与仓库现行规范。

# 给Codex的专题说明

请基于本资料包，为我的museum-notes网站制作一个与“罗马石棺”并列的青铜专题。先读仓库AGENTS.md、项目说明和现有专题结构，沿用设计系统与发布惯例，不擅自重做既有站点。

建议题名：**希腊与罗马世界的青铜：身体、权力与幸存**。路径可采用`greek-roman-bronzes/`，先检查是否已有约定或重名。范围以我实际看过的作品为核心，不把未见名作算成我的观看记录。

## 先读哪些资料

1. README.md：统计和最重要的核查结果。
2. catalogue.json、image_manifest.csv：作品与照片/展牌的准确对应。

## 数据与图片的硬要求

- 45张上传图片中，44张与艺术专题有关（24张作品图、20张展牌/背景图）；1997是无关机器人海报，已经从photos/排除，不要出现在网站。
- 18组观看记录、8家博物馆；其中17组古代雕塑/装饰＋母狼年代争议对照。组数不是完整雕像数，更不是独立馆藏号总数。
- 君士坦丁头/手/球有三个编号，仍以同柜观看组组织；原配关系待研究。尼米手形梁端包套有两件，1993与1994是不同视角而非三件。阿波罗本体与手/小动物是一个研究组。
- shared labels1973、1974仅存一份，让相关条目引用。不要复制或重复统计。
- 原图、展牌原图保持原始字节与文件名。派生缩略、裁切、旋转阅读版另存，保留原图入口。竖幅雕像正文应能看全身，不能只剩躯干封面。
- 背面图1963、骑马像三个角度、阿波罗分离残件、技术展牌应进入灯箱，不当作重复文件丢弃。
- 原文件名中的20261108是导出命名，不能用作参观日期。所有visit_date目前为空。

## 内容结构

首页要有少量大图、清楚的观看入口、简短个人导言。导言只能表达我已明确说过的兴趣，或写成中性的主题引导，不虚构某件像让我哭了、站了很久或看过几次。

建议四条主题线：

1. **身体与休息**：拳击手、刮身者头像、拔刺少年、阿波罗。
2. **英雄与权力**：所谓王子、休斯顿英雄化人物、马可·奥勒留、君士坦丁遗存。
3. **神祇与用途**：赫拉克勒斯、酒神、祭仪侍童、沃尔特斯少年、美杜莎与手形船饰。
4. **残件与幸存**：塞浦路斯腿部、帕尔梅巷马牛；母狼置于明确的年代争议/后世接受栏。

核心精读可优先拳击手、王子、马可·奥勒留、梵蒂冈赫拉克勒斯、克利夫兰阿波罗、金贝尔头像、休斯顿英雄像。其他条目有基本资料与具体观看提示即可，不强行写成长篇。

每件提供“意义／看什么／一个记忆点”，深入资料可折叠。保留所有已识别条目，精读深度分级不等于删掉一般作品。

## 比较、地图与时间线

- 地图按观看博物馆组织，8家地点与作品数可筛选；没有证据的出土地和流转路线不画成实线。
- 时间线表现区间与不确定性。b10、b11等不能显示伪造确年；母狼的两套年代分开表现，不纳入确定的古代主线。
- 比较模块选3至4组，详见历史文件；重点让读者在自己的照片中找到证据。
- 可与罗马石棺专题互链酒神、赫拉克勒斯与英雄化形象，也可建立“从浮雕叙事到圆雕身体”的入口。不能假装这批来自同一次参观。

## 必须准确处理的研究问题

- 梵蒂冈1996：Hercules Mastai，圆厅，鎏金铜，高383cm；修复项目252。现存铜像罗马时代，不能用希腊原型前390–370年定年。
- 母狼：传统古代归属与科学测年中世纪说并列，不能宣传为确定的公元前5世纪古代青铜。
- 克利夫兰阿波罗：Praxiteles或追随者；蜥蜴杀手/皮同杀手有不同解释，不署为无争议大师亲作。
- 沃尔特斯少年23.71：当前官网公元1世纪，现场牌前1世纪。明确保留冲突，不自行解释改年原因。
- 卢浮宫Br69：当前目录前475–450，现场牌约前490–450；与大英头像的关联保留probably。
- 拔刺少年：综合不同风格不等于现代拼接两个年代的残像。
- 尼米美杜莎及手形构件：是船用装饰；仅凭黄色照片不写鎏金。档案照片号不是器物号。
- b07、b08、b13、b14未知馆藏号留空或显示待核，不填猜测数。
- 当前官网在展状态是有日期的查询记录，不是我参观时的状态；尤其阿波罗不能因现官网Notonview删除我的实见照片。

## 背景补充

做一个短小、可以反复参考的“历史与观看”单元：制作与原型的区别、失蜡和分铸、铜像的颜色、回收与幸存、修复和辨识。相关人物/故事只讲到本批作品需要的程度，可简述赫拉克勒斯狮皮与金苹果、阿波罗与蜥蜴/皮同、美杜莎、酒神、马可·奥勒留与君士坦丁、刮身者与拳击。

研究记录的边界用自然语言呈现，不让页面变成开发说明。引用优先官方馆藏、研究论文和我拍的展牌。每件尽量有事实来源；推断、传统称呼与未知字段清楚区分。

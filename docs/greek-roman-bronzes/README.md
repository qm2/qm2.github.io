# 希腊与罗马世界的青铜：身体、权力与幸存

研究核查日期：2026-11-08。依据用户实拍、现场展牌、馆藏记录与注明的研究文献整理。未确认的参观日期全部留空；文件名中的20261108不是参观日期。

## 结果与计数

- 上传45张图片，其中44张与专题相关，1张机器人海报（1997）排除。
- 44张相关图片包含24张作品照片、20张展牌或背景说明照片。
- 配成18组观看记录，来自8家博物馆；其中17组古代雕塑/装饰，另1组为母狼年代争议对照。
- “组”并不等于单一馆藏号：君士坦丁头、手、球为三件编号遗存；尼米手形梁端包套为两件；克利夫兰阿波罗另有分离部件。不得将18组宣传为18尊完整雕像。
- 全部18组均已辨认；未解决的问题主要是少数馆藏号、年代范围、作者归属与残件是否原配。

## 最重要的核查

1. **没有展牌的梵蒂冈像（1996）已确认**：Hercules Mastai，圆厅，鎏金青铜，高383厘米；馆方修复项目列号252。详见b15与专项核对文件。
2. **母狼不是无争议的古代作品**：保留旧展牌，但作为科学测年与罗马形象后世生命的对照，不放进确定年代的核心古代时间线。
3. **沃尔特斯少年像出现资料冲突**：实拍展牌前1世纪，当前官网公元1世纪。两项均保留，不声称已知道改年的原因。
4. **不要把制作年代、希腊原型年代、艺术家生卒年代混写**：休斯顿英雄像、金贝尔头像和梵蒂冈赫拉克勒斯尤其容易出错。
5. **同一陈列不保证同一古像**：君士坦丁头像、手和球要保留原配关系疑问；尼米手形装饰则本来就是船梁构件。

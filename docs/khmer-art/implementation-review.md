# 高棉专题实现复核

主包与Harihara补充包合并，未修改任何原始照片。新图以文件键配对，不伪造原批序号。最终58条记录、120张照片、11个观看机构、69页；53条古代作品／组合、3条近代翻模、1条模型、1条仅展签，古代组内含O06暂名记录。

实际复核馆方来源：CMA《Moving Mountains》全文；Met 67.234；Guimet巨人栏杆、山墙说明；Kimbell AP 1966.09与AP 1988.01官方检索正文（直连403）；Smithsonian展览与所有权公告官方检索；UNESCO吴哥；Hanwong等2024年论文可读网页内容。其余来源沿用资料包查阅记录，逐项见sources.json，不冒称全读。

主包review.html、五张contact sheets、全部原图缩览及关键展签逐一对照。十张展签衍生图转正，其中3557复核后改为-90度并使用v2文件；原图不改。120张自拍对应483项已上传校验资源，含3张废弃的旧版3557预览，页面仅引用正确版本。

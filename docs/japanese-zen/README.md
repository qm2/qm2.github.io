# 日本禅宗书画：维护与研究记录

新专题 `/museum-notes/japanese-zen/`，日本艺术入口 `/museum-notes/japanese-art/`。

## 数据与构建

- `museum-notes/japanese-zen/data/works.json`：19件／组的唯一作品记录、正文、收藏节点、题跋与关联作品。稳定ID为j01–j19。
- `photos.json`：43张原照的文件、SHA-256、所属作品、角色、展示旋转和响应式版本。24张作品／局部照、19张展签。
- `opening.json`：用户许可采用的三段个人前言与寒山题引。
- `editorial.json`：四组主线＋延伸比较，以及时间线。
- `sources.json`：来源、核查范围与访问状态。移交包研究与本次直接阅读区分；MFAH豪潮及金贝尔若冲馆录使用可读的官方检索内容，未声称直接读到受限原页。
- `scripts/build_japanese_zen.py`：生成首页、十九篇详情、日本艺术入口，幂等更新博物馆首页卡片。已加入 `scripts/build_museum.py`。
- CSS与JS均限定于新专题；复用既有Caravaggio灯箱，不增加依赖。

构建：`python3 scripts/build_museum.py`。
检查：`python3 scripts/check_japanese_zen.py`、`python3 scripts/check_japanese_zen_browser.py`。后者需要本地端口与Chromium许可，截图仅保存在`/tmp/zen-*.png`。

## 摄影与增补

源包43张JPEG原样保留在`images/originals/`，SHA-256均与移交清单一致。生成400/900/1600宽度目标的WebP，不放大原始像素。1732展签展示版逆时针旋转90度，原照不变；未作颜色修复、去反光或补绘。所有画面均来自用户，联系表和移交研究草稿未加入公开资源。

新照片追加photos记录，并将照片号追加至原作品的photos或labels；不要因重访另造作品。未知参观日期为null，不从文件名填入。新作品追加稳定ID，再在editorial中选入一组；数量及目录由数据派生。增加照片时需用Pillow生成同规格展示副本并记录实际像素。原始作品图始终可通过详情灯箱打开。

## 保留的问题

1. Gasoku的汉字姓名与生平；j15印章暂读Moriyoshi Seiyō，尚无可靠汉字姓名及明确师承。
2. 仙厓《富士山》展签年代1700–1800很宽，尚无更精确单件馆录。
3. 无可靠完整释文的作品不增设题跋占位或猜写文字。目前七件使用公开馆录释文；梦窗“応”注明规范为“應”，其余保留馆方字形。
4. 旧签与现行馆录差异：绝海生年、慈云编号与赠藏年、隐元卒年、清岩借展转赠藏，分别保留资料注。
5. 铁斋1915年作品不与大都会1914年另一观音混同。近代两件1932观音无原配套证据。
6. 大部分作品的早期日本递藏资料仍不完整；未用收藏家整体经历代替单件来路。

后续可优先研究：仙厓富士山的两侧题字；铁斋两件题赞与坂本光净的单件捐赠档案；Gasoku及剃发像的作者归属。取得可靠释文或原始记录后再补，不用图像猜读填满。

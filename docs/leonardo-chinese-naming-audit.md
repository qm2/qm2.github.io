# 达·芬奇专题中文名称审核

审核日期：2026-09-24。此表在修改作品数据、生成器和页面之前建立。

原则：以简体中文美术史及博物馆惯用名称为准；馆方中文译名是重要依据，但不是排除其他已有通行译名的理由。未做词频统计，不把单一机构的写法称为唯一标准。只改名称，不改作品选择、作者归属、年代、故事判断、观看笔记或视觉设计。下表中的“保留”是主动审核后的决定。

## 需要个人判断的范围

没有必须暂停修改、等待用户裁决的事实性冲突。La Belle Ferronnière、Verrocchio、Melzi、Anne 等存在有来源的异译；按用户“当前名称已通行就保留”的原则处理。如将来希望全站严格采用某一套出版物的译名，这些才需要统一的编辑偏好决定。本轮不把“没有唯一译名”包装为已解决的学术共识。
